# One controlled automatic-routing trial

Planned before Start: **one attempt**, using the unchanged easy label-normalizer
fixture and independent tests from `docs/trials/matrix/run_live.py`. The worker
implements Unicode-preserving whitespace normalization with type validation and
a runnable README example. One item, one exact unittest command; no merge/push.

Automatic remote selection may use public-free eligible routes or the already
operator-authorized included Kiro scope: exactly `kiro/claude-sonnet-4.5` and
`kiro/claude-haiku-4.5` on the inspected connection revision. No local or paid
fallback. The worker/reviewer preference is retained, but the automatic selector
must establish eligibility, distinct reviewer, capability and availability.
No task provider is injected after preparation. New included models are not
implicitly authorized. Global settings and other work are unchanged.

Measurement mode removes arbitrary cumulative work/check caps while retaining
command consent, transport guards, spending/access policy, usage and Pause.
Historical pinned runs of this same small fixture took roughly 49–195 seconds,
11–17 requests, and 56,298–111,141 accounted tokens; failures also took longer.
Expect minutes and a dozen-plus requests plus selection probes, not a fixed cap
or a promise. Included marginal estimates are not provider invoices.

The two-phase observer freezes the final committed app/runtime, exact fixture
and acceptance hashes, configuration/access hash, and inspected proposal before
Start. Their concrete identities belong in the generated baseline/result record.
Observe without coaching or unchanged Resume. Verify matching receipts, current
required checks, unchanged acceptance/source main, and the README example.
A failed selection/run is retained as a result, not silently retried. Any later
comparison needs a separate proposal with matched versions. One observation does
not establish production success rates or justify restrictive default budgets.
